Native Sleek and theme marketplace

Actual Linux/X11 demo captures. Sleek ports the source CSS appearance into native widgets: gradient navigation, filled selection, rounded artwork, quieter controls, outlined toggles, styled track rows and a full-width player seek bar. The default light and dark layouts stay available. The curated catalog starts with Sleek's 19 bundled schemes and works offline.

Before Home captures were taken before implementation. Sleek's baseline is the previous color.ini import using the same Wealthy scheme with native appearance disabled. Marketplace Before shows the earlier Appearance settings, since the marketplace did not exist. Demo artwork requests are unavailable in this environment, so the app's normal placeholder artwork is visible. No screenshot is a mockup.

Install enables Sleek without changing the active theme. Apply selects the previewed scheme; Remove returns an active selection to the built-in appearance and preserves imported files. Package updates arrive with application updates. This is a native port, not a Spotify CSS or JavaScript runtime. Pinned upstream source. MIT attribution is included in the theme package.

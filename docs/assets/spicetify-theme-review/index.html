Spicetify theme import

Actual Linux/X11 demo captures at 1280×800. The Settings search is filled through real keyboard input. The importer adds one row to Appearance; existing theme controls and layouts are preserved.

Example: Sleek, Wealthy scheme. All 19 schemes were imported by the actual importer. Only color.ini is read; source files are preserved. Imported palettes can be selected and cached using the existing theme system. CSS, JavaScript, fonts, and layouts are not imported.
